# 360° MDL — website, Index Calculator and Navigator

Public site of the **360° MDL — Multidimensional Literature Review Model, Version 2026** by Miltiadis D. Lytras: https://mlytras.github.io/360mdl/

- `index.html` — landing page (method, start-here doors, Navigator, calculator, indices, responsible-AI protocol, resources, citation)
- `starter.html` — Review Starter: guided planner (protocol, search strings, stream plan, pre-filled toolkit)
- `calculator.html` — the Index Calculator, one self-contained file (MIT licence)
- `navigator.html` and `360mdl-navigator.zip` — the 360° MDL Navigator v0.1.2, a Claude Skill (scripts MIT; instructions CC BY 4.0)
- `360MDL_Index_Calculator_User_Guide.pdf` — User Guide and Claude protocol (CC BY 4.0)
